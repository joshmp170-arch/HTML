# HTML

Aquí van los códigos de HTML que aprendemos en la clase de Programación Web I.
**HTML (HyperText Marjup Laanguage)** no es mas que un lenguaje de programación. Es un keguaje de marcado que usa etiquetas para definir su estructura y el significado del contenido de una página.

Piensa en HTML como los planos de una casa. Los planos no son la casa en si, pero definen dónde va cada pared, cada puerta o cada ventana. De la misma forma HTML no define colores, tamaños, ni animaciones, *define qué es cada elemeto y cómo se relaciona con los demás*

HTML funciona con etiquetas *(tags)*. Cada etiqueta se escribe entre corchetes angulares o los símbolos de <> y la mayoría tiene una etiqueta de apertura y una de cierre:

```
<h1>Este es un título principal</h1>
<p>Este es un párrafo de texto.</p>
<a href="https:google.com">Este es un enlace</a>
```
## Atributos

Las etiquetas pueden tener atributos que agregan información adicional. En el ejemplo del enlace. `href` es un atributo que indica hacia dónde dirige el enlace.
